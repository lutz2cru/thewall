Comment obtenir un token ?
  1. Le propriétaire du dépôt t'ajoute comme collaborateur (Settings → Collaborators) ou comme membre de l'organisation.
  2. Crée un token « fine-grained » : accès au seul dépôt du mur, permission Contents : Read and write, avec une date d'expiration.
  3. Si le dépôt appartient au compte perso de quelqu'un d'autre, GitHub ne le propose pas aux tokens fine-grained : crée alors un token classique avec uniquement la case public_repo.
  4. Colle le token ci-dessus. Ne le partage jamais : il permet d'écrire dans le dépôt en ton nom.
